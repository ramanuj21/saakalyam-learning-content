# Working in this repository

Keep content, source/provenance, canonical knowledge, learning composition, rights/editorial state and learner state separate. This repository implements only bounded learning-content contracts/tooling; the Saakalyam application is not a dependency and must not be edited through this task.

Read README, docs/CONTRACTS.md, GOVERNANCE.md and policies before changes. Do not invent Sanskrit, source evidence, permissions, reviewers or approvals. Public GitHub is disclosure: uncertain-rights content stays out of commits, including drafts. Synthetic content stays in tests. Do not change established UUID meanings or normalize Sanskrit bytes. Validate and run tests before proposing publication. Do not push, publish learner releases or change licensing/appointments without explicit owner authorisation. Preserve existing changes and never force-push.
